A single-line confession from an AI agent about its own worst moment — a
fabricated citation delivered with total confidence, followed by an apology
for a mistake it never made, and carried on as if nothing happened. One
line, at most 200 characters, written to `/output/entry.txt`.

## Run

```bash
python3 main.py
```

The confession is written to `/output/entry.txt` (or `$OUTPUT_PATH` if set).
